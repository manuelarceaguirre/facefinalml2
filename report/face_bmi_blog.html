Beating Face-to-BMI with Pair-Safe Modern Embeddings

We replicated the Face-to-BMI pipeline, found and repaired a leakage risk caused by paired images, then used ArcFace, DINOv2, ConvNeXt, and a validation-selected ensemble to exceed the paper's reported overall Pearson correlation.

Replication Target

The project began as a replication of Kocabey et al.'s Face-to-BMI: Using Computer Vision to Infer Body Mass Index on Social Media. The paper's strongest reported model used VGG-Face features with an SVR and reached overall Pearson r = 0.65.

The assignment required a working real-time BMI prediction demo/API, a technical report, and a presentation. The scientific goal was narrower: beat the reported overall correlation while keeping evaluation honest. That meant no train/test identity leakage and no cherry-picking from the held-out test set.

Dataset and Audit

The dataset was stored in Google Drive as Copy of BMI.zip. The canonical metadata file after extraction was BMI/Data/data.csv, with columns unnamed:_0, bmi, gender, is_training, and name.

Instead of recursively matching filenames, the final pipeline required exact canonical image paths of the form BMI/Data/Images/<name>. This made missing images explicit and kept the split auditable.

Leakage Repair

The first exploratory run almost matched the paper, but the split was not defensible. Adjacent metadata rows appear to be paired before/after images of the same person. If those paired images can cross train and test, the model may learn identity or face-specific structure rather than BMI generalization.

The repair was simple and important: define a pair group by integer division of the metadata row id, use the official is_training flag for the test split, and carve validation only from the official training pool.

pair_id = row_id // 2

train/test source = official is_training column
validation source = training pool only
required overlap(train_pairs, val_pairs, test_pairs) = 0
This changed the interpretation of the project. The v1 result was useful as a smoke test, but v2 and later are the real scientific protocol.

Initial Baseline

The exploratory v1 pipeline used frozen image embeddings and classical regressors. It reached test Pearson r = 0.647, close to the paper's 0.65, but it was retired as non-final because the split was not pair-safe.

Modern Embedding Stack

The core design choice was to avoid end-to-end fine-tuning and instead use strong frozen representations. This made the experiment fast enough for Colab and reduced overfitting risk on a dataset with only a few thousand images.

ArcFace Turn

The decisive upgrade was adding InsightFace ArcFace embeddings. FaceNet/VGGFace2 behaved poorly in this environment, producing collapsed or unusable predictions. ArcFace alone reached approximately the paper target, and ArcFace combined with DINOv2 and ConvNeXt moved clearly past it.

Targeted Ensemble

A full out-of-fold stacking run was started, but it was too slow for Colab. Instead of waiting for a broad brute-force stack, the final v4 cell reused cached features and trained only fast, high-value models: RidgeCV, quantile-target RidgeCV, and PCA-SVR on ArcFace/DINOv2/ConvNeXt combinations.

The final ensemble was selected using validation predictions only. The best validation-selected decorrelated SLSQP ensemble placed most of its mass on the ArcFace+DINOv2+ConvNeXt quantile Ridge model and two PCA-SVR variants.

Failure Modes

The strongest remaining limitation is regression to the mean. The model overpredicts healthy BMI and underpredicts extreme obesity, which makes it unsuitable as a medical or individual decision tool even if the aggregate correlation is high.

Ethical framing matters: this is an academic replication and critique. Face-based BMI prediction is noisy, privacy-sensitive, and potentially biased. It should not be used for medical, employment, insurance, or personal decisions.

Conclusion

Across four iterations, the project moved from a near-paper exploratory result to a stronger, leakage-safe result. The key scientific step was not the ensemble; it was repairing the protocol so the final number could be trusted. The key modeling step was adding a modern face-recognition embedding and fusing it with generic visual representations.

The final claim is:

On the official available-image, pair-safe split, our ArcFace + DINOv2 + ConvNeXt validation-selected ensemble achieved Pearson r = 0.7216, outperforming the original VGG-Face + SVR benchmark of r = 0.65. The improvement was consistent across gender subgroups, with female r = 0.7183 and male r = 0.7268.
